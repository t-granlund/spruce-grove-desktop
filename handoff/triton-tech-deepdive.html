the plugin model

Extend it without forking it

tierlives atwho owns ittrust
builtincode_puppy_core_plugins/the projectdiscovered via entry points
user~/.spruce_grove/plugins/you, on every projectyour machine, your call
project<repo>/.spruce_grove/plugins/the repo, shared via gitSHA-256 gated — nothing loads until you type "trust"
the detail that matters

Project-plugin trust is a hash of the directory, scoped to that project path. Any file change reverts to untrusted. Runtime state is banned from the plugin dir — because state next to the code would self-tamper the hash. Accepted plugins hot-load with no restart; /plugins revoke pulls trust.

The life of a prompt

step 1 · compose

You type, or you speak. The prompt lands in the shell, which never parses it — it hands the turn to the engine whole.

voice · on-device

Speak it, and the audio stays home

Mic → local Whisper → an editable prompt. The audio never leaves the machine. But the interesting engineering is the guard against a model that confidently invents sentences.

the failure

Whisper hallucinates on silence — repeating stock phrases like "Thank you." across a pause. A naive transcript reads as real speech.

density, per second of speech

Silence is measured with ffmpeg silencedetect at -30 dB, 0.5 s min, and subtracted from duration. The guard is characters ÷ speech seconds, floor 2.0.

stock-token residue

Every known stock phrase is stripped, then the remainder is checked. Repeated "Thank you." leaves nothing — and dies. Real speech that says "thank you" survives.

fails safe

If silence detection fails, it falls back to total duration — so the guard can only get less strict, never more.
